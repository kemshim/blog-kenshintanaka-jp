田中けんしん（Kenshin Tanaka）。このブログを書いている人。 まだ自己紹介を書き慣れていないので、この頁はときどき書き直します。

このブログについて

百年後の誰かにも届くかもしれない文章を置く場所として始めました。 漫画『チ。』で地動説のために命を賭けた登場人物、ヨレンタの 「文字は奇蹟」という台詞が起点です。

ここに置く文章は、編集は最新のツール（Claude Code）に任せつつ、 成果物としては素の HTML と CSS だけを残す、という方針で作っています。 ビルドツールも JavaScript も Web フォントも使いません。 中世の写本が複数の修道院に複製されたから現代まで生き延びたように、 このサイトも GitHub、Cloudflare Pages、いくつかのアーカイブに 分散して置いています。
