はじめに

2026-04-25

このブログは、百年後の誰かに届くかもしれない文章を置く場所として はじめる。漫画『チ。』のヨレンタが言う「文字は奇蹟」という台詞が 頭を離れなかった。

だから書く器も、なるべく長く壊れないものにしたい。素の HTML と CSS だけで組み、ビルドツールも JavaScript も Web フォントも 使わない。中世の写本が複数の修道院に複製されることで生き延びた ように、ここも GitHub と Cloudflare Pages と、いくつかの アーカイブサービスに分散して置く。

何を書くか

毎日の出来事というより、あとで読み返して「そうだった」と 思えるような種類のことを書きたい。速度より持ちを優先する。 書き終わるまで時間がかかってもよい。

まだ練習中なので、しばらく整わない。
